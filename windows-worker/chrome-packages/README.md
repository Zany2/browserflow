# Chrome Packages

Put the Chrome 136 installer or portable package for BrowserFlowWorker users in this directory.

Recommended naming:

- `Chrome-136-x64-offline-installer.exe`
- `Chrome-136-win64-portable.zip`

Notes:

- Keep the original Chrome executable as `chrome.exe` when possible.
- BrowserFlowWorker can select any `.exe`, but using the original `chrome.exe` is still the safest option.
- Do not commit large installer files unless the repository is intended to store binary packages.
